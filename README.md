# Custom Capes

Mod de capas personalizadas para Minecraft 1.8.9, desenvolvido inteiramente por **Thiago Klein**. Oferece uma experiência fluida e profissional para personalização do personagem.

## Funcionalidades

- **Vasta Seleção:** Diversas capas icônicas (Minecon, Migrator, Galaxy, etc) inclusas.
- **Interface Profissional:** Menu intuitivo (tecla **P**) com pré-visualização 3D do jogador em tempo real.
- **Persistência:** Sua escolha de capa é salva localmente e carregada automaticamente.
- **Compatibilidade:** Desenvolvido especificamente para Forge 1.8.9.

## Requisitos

- Minecraft 1.8.9
- Forge `1.8.9-11.15.1.2318` ou superior

## Instalação

1. Instale o [Minecraft Forge 1.8.9](https://files.minecraftforge.net).
2. Coloque o arquivo `customcapes-1.0.0.jar` na pasta `mods` do seu Minecraft.
3. Inicie o jogo usando o perfil do Forge.

## Como Usar

| Ação | Comando |
|---|---|
| Abrir Menu de Capas | Pressione **P** em jogo |
| Selecionar Capa | Escolha na lista → **Select** |
| Remover Capa | Clique em **Remove Cape** |
